Welcome to the **Anime Streaming Platform**! A modern, fast, and sleek web application designed for anime enthusiasts to discover, organize, and watch their favorite shows and movies seamlessly. ✨

---

## 🌟 Objective

The main goal of this project is to provide a smooth, user-friendly, and interactive interface for browsing anime. Whether you're looking for the latest seasonal releases, a specific movie, or just want to organize your personal watchlist into custom playlists, this platform aims to deliver a premium streaming-like experience right in your browser.

## 🚀 Features

- **📺 Extensive Browsing:** Explore popular anime, recent releases, movies, and series with dynamic genre filtering.
- **🔍 Smart Search:** Instantly find your favorite shows with real-time search capabilities.
- **❤️ Favorites System:** Save your top picks to a dedicated favorites list for easy access.
- **📂 Custom Playlists:** Create, manage, and curate your own playlists to group anime exactly how you want.
- **🎬 Movie & Episode Support:** Differentiated logic for movies (instant watch) and series (episode selection).
- **📱 Fully Responsive:** Beautifully crafted UI that works flawlessly on desktop, tablet, and mobile devices.
- **⚡ Blazing Fast:** Built with Vite for instant server start and lightning-fast HMR.

## 🛠️ Technologies Used

This project is built using modern web development tools:

- **[React 19](https://react.dev/):** The core library for building the dynamic user interfaces.
- **[Vite](https://vitejs.dev/):** Next-generation frontend tooling for an extremely fast development and build process.
- **[React Router v7](https://reactrouter.com/):** For seamless client-side navigation and SPA (Single Page Application) routing (using `HashRouter` for GitHub Pages compatibility).
- **[Lucide React](https://lucide.dev/):** Beautiful, consistent, and customizable SVG icons.
- **CSS3 / Vanilla CSS:** Carefully crafted custom styles without relying on heavy UI frameworks, providing a unique and lightweight aesthetic.
- **[GitHub Pages](https://pages.github.com/):** Deployed effortlessly using `gh-pages` for fast and reliable hosting.

## 📦 Getting Started

Want to run the project locally? It's simple!

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ainlautaro7/anime-streaming-platform.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd anime-streaming-platform
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open your browser:**
   Visit `http://localhost:5173` to see the app in action!

## 🌐 Deployment

This application is configured for easy deployment to GitHub Pages.

To build and deploy the app, simply run:
```bash
npm run deploy
```
*Note: This runs the build process and pushes the `dist` folder to the `gh-pages` branch automatically.*
